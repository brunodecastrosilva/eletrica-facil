# Elétrica Fácil

Orçamentos de elétrica sem calculadora. App web instalável: no iPhone, abra o endereço no Safari e toque em **Compartilhar → Adicionar à Tela de Início**.

- `index.html` — o app inteiro (dados salvos só no aparelho)
- `sw.js` / `manifest.webmanifest` / `icons/` — instalação e uso offline
