# Elétrica Fácil

Orçamentos de elétrica prontos em minutos, direto no celular.

- Monte o orçamento escolhendo serviços e materiais da sua tabela de preços
- Envie a proposta em PDF (folha A4) ou pelo WhatsApp, com QR code do Pix da entrada
- Acompanhe o que está aguardando resposta, aprovado e concluído; gere o recibo no fim do serviço

App web instalável: no iPhone, abra o endereço no Safari e toque em **Compartilhar → Adicionar à Tela de Início**. No Android, use **Instalar app** no menu do Chrome. Os dados ficam só no aparelho; use **Ajustes → Exportar cópia** para guardar um backup.

- `index.html` — o app inteiro
- `sw.js` / `manifest.webmanifest` / `icons/` — instalação e uso offline
